# Lumen Player

Минималистичный тёмный видеоплеер для Windows на базе libmpv (движок `gpu-next` / libplacebo).

## Что умеет

- **HDR10 / HLG / Dolby Vision (P5, P7, P8)** — на обычном SDR-мониторе применяется тон-маппинг
  (bt.2390 + динамический пик яркости), поэтому картинка не «выцветает» и не получается серой.
  На HDR-мониторе включается HDR-passthrough. Режим переключается клавишей `H`.
- **Растяжка** (клавиша `A` или ПКМ → Растяжка): по размеру, заполнить с обрезкой, растянуть, 16:9, 4:3, 21:9, 1:1.
- **Субтитры как в VLC**: файлы `.srt/.ass/...` рядом с видео (и в папках `Subs`, `Subtitles`) подхватываются
  автоматически, кодировка определяется (UTF-8 / cp1251). `V` — смена дорожки, `S` — загрузить файл,
  `Z`/`X` — сдвиг по времени. Перетаскивание .srt на окно тоже работает.
- Аппаратное декодирование, Direct3D 11, быстрое масштабирование (spline36).
- Тёмная тема, ничего лишнего: панель управления снизу, в полноэкранном режиме она скрывается.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел / ЛКМ | пауза |
| Двойной клик / `F` / Enter | полный экран (Esc — выход) |
| ← → / Shift / Ctrl + ← → | перемотка 5 / 30 / 120 с |
| ↑ ↓ / колесо | громкость |
| `M` | без звука |
| `A` | режим растяжки |
| `H` | режим HDR |
| `V` / `B` | субтитры / аудиодорожка |
| `O` / `S` | открыть видео / субтитры |
| `Z` `X` | задержка субтитров −/+ 0.1 с |
| `[` `]` `Backspace` | скорость −/+/сброс |
| `,` `.` | кадр назад / вперёд |
| `I` | статистика (кодек, HDR-метаданные, fps) |
| ПКМ | меню |

## Сборка установщика (.exe)

### Вариант 1 — GitHub Actions (проще всего)
1. Создайте репозиторий на GitHub и загрузите туда эту папку.
2. Вкладка **Actions → Build Windows installer → Run workflow**.
3. Через несколько минут скачайте артефакт `LumenPlayer-Setup` — это готовый установщик.

### Вариант 2 — локально на Windows
1. Установите Python 3.10+, [7-Zip](https://7-zip.org), [Inno Setup 6](https://jrsoftware.org/isinfo.php).
2. Скачайте libmpv: <https://github.com/shinchiro/mpv-winbuild-cmake/releases> → `mpv-dev-x86_64-*.7z`,
   достаньте `libmpv-2.dll`, переименуйте в `mpv-2.dll` и положите рядом с `build.bat`.
3. Запустите `build.bat` → `Output\LumenPlayer-Setup.exe`.

### Запуск из исходников (для проверки)
```
pip install PySide6 python-mpv
# положите mpv-2.dll рядом с main.py
python main.py "C:\video\film.mkv"
```

## Заметки

- Dolby Vision: профили 5/7/8 обрабатываются libplacebo. Для P8 (HDR10-совместимого) на SDR-мониторе
  тоже работает тон-маппинг. Проприетарная цветокоррекция Dolby Vision «один в один» недоступна
  ни в одном плеере вне сертифицированных устройств — результат максимально близкий.
- Приоритет языка субтитров/аудио задан в `main.py` (`slang`, `alang`): сейчас `ru, en`.
- Если стоит слабая видеокарта, замените `scale="spline36"` на `"bilinear"`.
